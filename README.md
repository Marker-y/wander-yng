# wander-yng

A rhythm game inspired by Piano Tiles, with tap and hold notes.

## Features

- 🎮 4-lane rhythm gameplay (tap + hold notes)
- 🎵 Custom chart editor with publish functionality
- 👤 User accounts with admin approval system
- 🎨 3 themes: dark, light, pink-blue
- 📱 Mobile-friendly landscape design
- 🔗 Shareable chart links

## Play

Open the deployed URL and start playing!

### Default Admin Account
- Username: `admin`
- Password: `admin123`

## Deployment

This app uses only Node.js built-in modules (no external dependencies).

1. Push to GitHub
2. Deploy to Railway/Render/Vercel
3. Set environment variables if needed:
   - `PORT` (auto-set by hosting platform)
   - `HOST` (default: `0.0.0.0`)
